# ALIGN Structure Recognition Parity Package

This directory is a portable subset of ALIGN for structure recognition only.
It was generated by `make_align_structure_parity_package.py` from an ALIGN
checkout.

It contains:

- `align/compiler/structure_recognition.py`
- the compiler/schema modules it depends on
- `align/config/basic_template.sp` and `align/config/user_template.sp`
- `pdks/FinFET14nm_Mock_PDK/models.sp`
- a lightweight PDK `__init__.py` shim so recognition does not require the full
  layout generator stack
- `recognize_one_netlist.py`, a single-netlist CLI wrapper

Because this package runs the same ALIGN structure-recognition API and template
library, its JSON output is intended to match the original ALIGN framework for
this topology-recognition task, assuming the same Python dependency versions.

## Runtime dependencies

Install the lightweight Python dependencies used by ALIGN's recognizer:

```powershell
pip install "pydantic>=1.9.2,<2.0" networkx pyyaml z3-solver flatdict more-itertools colorlog
```

Important: use Pydantic v1. Pydantic v2 changes `__root__` model behavior and is
not compatible with this ALIGN code path.

## Usage

Recognize one netlist and write JSON:

```powershell
python recognize_one_netlist.py path\to\netlist.sp --top TOP_SUBCKT -o path\to\result.structure.json
```

If `--top` is omitted, the wrapper chooses the top `.SUBCKT` using the same rule
used by the dataset generator:

1. `.SUBCKT` matching the file stem;
2. else `.SUBCKT` matching the parent directory name;
3. else first `.SUBCKT` in the file.

Print to stdout instead of writing a file:

```powershell
python recognize_one_netlist.py path\to\netlist.sp --top TOP_SUBCKT
```

Show a short summary:

```powershell
python recognize_one_netlist.py path\to\netlist.sp --top TOP_SUBCKT -o result.json --summary
```
